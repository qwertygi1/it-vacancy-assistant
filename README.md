# IT Vacancy Assistant (v0.2.0-beta)

Интеллектуальный карьерный ассистент и аналитик IT-рынка вакансий с Telegram-каналов Казахстана на базе локальной LLM (**Ollama / Qwen 2.5:7b**), **PostgreSQL** и **Telethon**.

## Возможности (Beta v0.2.0)

### 📊 1. Модуль аналитики рынка (Market Intelligence)
- **Точные подсчеты без галлюцинаций**: агрегация данных (`COUNT(*) GROUP BY`) на уровне PostgreSQL по должностям, стеку, компаниям и формату работы.
- **Рейтинг востребованности**: моментальный ответ на вопросы *«Какая вакансия попадается чаще всего?»*, *«Какой стек самый востребованный?»*, *«Сколько раз встречался Python?»* с точными цифрами и процентами.
- **Устойчивость к разговорному контексту**: ассистент отличает вводные реплики пользователя от реальных поисковых фильтров.

### 📅 2. Контекст времени и точные даты
- **Хранение даты публикации (`published_at`)**: каждая вакансия сохраняет оригинальную дату и время поста из Telegram.
- **Понимание временных горизонтов**: ассистент в реальном времени знает период своей базы (*«В базе 856 вакансий с 01.06.2026 по 16.09.2026»*).
- **Гибкие границы сбора**: сбор за выбранные сезоны через `--since YYYY-MM-DD` и `--until YYYY-MM-DD`.

### 🔗 3. Прямые ссылки на посты в Telegram
- Сохранение `channel` и `message_id` для каждого поста.
- В каждом ответе ассистент предоставляет прямую кликабельную ссылку на оригинальный пост в Telegram (например, `https://t.me/itvacancykz/2019`).

### ⚡ 4. Оптимизированный сбор данных
- Мгновенный пропуск уже сохраненных постов (1 мс) без лишних вызовов Ollama.
- Поддержка каналов Казахстана: `itcom_kz`, `itvacancykz`, `devs_kz`, `devkz_jobs`, `workitkz`, `zhumysbarit`.

## Быстрый старт

### 1. Запуск базы данных
```bash
docker compose up -d
```

### 2. Сбор вакансий
```bash
# Собрать вакансии за всё лето (с 1 июня):
.\.venv\Scripts\python parser.py --since 2026-06-01

# Собрать с ограничением по датам:
.\.venv\Scripts\python parser.py --since 2026-06-01 --until 2026-08-31

# Быстрое обновление (последние 50 постов):
.\.venv\Scripts\python parser.py --limit 50
```

### 3. Запуск карьерного ассистента
```bash
.\.venv\Scripts\python assistant.py
```
