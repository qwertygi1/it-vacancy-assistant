# IT Vacancy Assistant (v0.1.0-beta)

Интеллектуальный карьерный ассистент и поисковик IT-вакансий с Telegram-каналов Казахстана на базе локальной LLM (**Ollama / Qwen 2.5:7b**), **PostgreSQL** и **Telethon**.

## Возможности (Beta v0.1.0)
- **Сбор вакансий из Telegram**: выгрузка постов через Telethon из реальных каналов (itcom_kz, itvacancykz, devs_kz, devkz_jobs, workitkz, zhumysbarit).
- **Извлечение данных через LLM**: автоматическое структурирование (роль, грейд, стек технологий, удаленка, контакты для связи).
- **Оптимизация повторного сбора**: мгновенный пропуск уже сохраненных в PostgreSQL постов без повторного вызова нейросети.
- **Гибкий парсинг**: поддержка флагов --limit, --since YYYY-MM-DD, --channel.
- **Живой карьерный диалог**:
  - Распознавание намерений (поиск vs диалог/советы по карьере).
  - Память контекста диалога (уточняющие вопросы).
  - Динамическая осведомленность о состоянии базы вакансий в реальном времени.

## Быстрый старт

### 1. Запуск базы данных
`ash
docker compose up -d
`

### 2. Настройка окружения
Скопируйте .env.example в .env и укажите свои параметры:
`ash
copy .env.example .env
`

### 3. Сбор свежих вакансий
`ash
# Базовый запуск (по 10 сообщений)
.\.venv\Scripts\python parser.py

# Сбор по 50 сообщений с каждого канала
.\.venv\Scripts\python parser.py --limit 50

# Сбор вакансий начиная с определенной даты
.\.venv\Scripts\python parser.py --since 2026-03-01 --limit 200
`

### 4. Запуск интерактивного ассистента
`ash
.\.venv\Scripts\python assistant.py
`
